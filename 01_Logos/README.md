# GroundSwell GS logo family — v2.0

The GS monogram uses the upper crest from the original New Wave Social Engineering mark. The curve passes through both initials; transparent vector masks preserve the negative-space channel on any background.

## Choose a file

| Family | Use |
| --- | --- |
| Primary | GS beside the complete GroundSwell wordmark; default logo |
| Endorsed | Primary logo with BY NEW WAVE for introductions and partnerships |
| Stacked | GS above the GroundSwell wordmark |
| GS | Closely cropped standalone initials; a wide transparent artboard |
| Mark | Standalone GS on a square transparent artboard for apps |
| Compact | Optical GS for 24–32 px square placements; stronger cyan wave |
| Micro | Solid GS initials for 16 px; no fine wave detail |
| Wordmark | GroundSwell lettering alone in familiar contexts |

Color uses navy initials and cyan wave. Reverse uses Cloud White initials and cyan wave for navy backgrounds. Navy and White are single-color masters; their negative-space crest remains transparent. Micro removes the crest for the smallest use.

SVG files are editable vectors with outlined lettering. PNG files have transparent backgrounds. The live-text companions require the included Plus Jakarta Sans font and preserve the hand-set wordmark spacing with explicit glyph positions.

## Scale and space

- Primary: at least 220 px wide.
- Endorsed: at least 300 px wide.
- Standard GS: at least 32 px wide; use Compact for 24–32 px square placements.
- Micro: 16 px square placements.
- Clear space around a complete lockup: at least half the visible GS height.

Small-size files use the original GS letter shapes with a slight spacing adjustment. Keep the supplied artwork intact and scale uniformly. The full original three-current New Wave mark remains a heritage reference in 02_Graphics and 07_Source_References.
