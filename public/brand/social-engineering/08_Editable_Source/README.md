# Editable source

All SVG artwork throughout this package is editable vector source. Logo text is outlined for stable display. The two live-text logo files in `01_Logos/Editable_Text` preserve explicit character spacing and require the bundled Plus Jakarta Sans font.

`Construction_Notes.json` records wordmark spacing, GS monogram construction, inherited crest provenance, optical-size variants, swell construction, and artboard sizes. The three `GS_Construction_*` SVGs preserve the master geometry. `build_guide.py` is the reproducible PDF guide source; it uses the artwork and original font files included in this package.

Fonts are distributed with their original license files. Original New Wave artwork is preserved in `07_Source_References`. No font software has been renamed or represented as a newly designed GroundSwell typeface.
