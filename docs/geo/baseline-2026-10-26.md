## 2. What crawlers receive without JavaScript

Fetched every URL in both sitemaps with a GPTBot user agent and again with a
plain curl agent; responses were byte-identical in size for the ten pages
compared both ways (no user-agent branching) [verified: `evidence/.../crawl-live.json`, `live/` fetch log].

- **Every New Wave IT page (41 of 51 sitemap URLs, plus all 8 blog posts) serves an empty `<body>`**: 1 word, 0 `<h1>`, no visible text. A non-JS crawler sees only the `<head>`: title, description, canonical, OG tags and JSON-LD. [verified]
- **The 8 GroundSwell pages** (`/social-engineering/groundswell` and its 7 metric pages) are the only pages with a prerendered body (551 to 4,290 words, one `<h1>`). [verified]
- The other 10 division pages serve a prerendered navigation only (link labels, no body copy). [verified]
- With JavaScript (mobile Chromium) the pages do render: home 673 words, `/services` 500, a blog post 1,533. [verified: `cwv-live.json`]
- `robots.txt` has one `User-agent: *` block allowing everything but `/admin*`, and lists both sitemaps. No AI-crawler rules exist, so GPTBot, OAI-SearchBot, ChatGPT-User, ClaudeBot, PerplexityBot, Google-Extended and CCBot are all **allowed** by default. [verified]
- `llms.txt` and `llms-full.txt`: **absent** (HTTP 200 with the HTML shell). [verified]
- `newwaveitfl.com` → 307 → `https://www.newwaveitfl.com/`; `http://www.` → 308 → https. [verified]

Prior finding on record: `docs/groundswell-seo-audit-2026-10-22.md` measured
the same empty body on the homepage and parked "extend prerendering to the
homepage and other static routes" as a follow-up. That follow-up is the main
Phase 2 item.
