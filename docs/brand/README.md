# New Wave IT Brand System

This directory contains the approved controlled-evolution New Wave IT brand reference package.

## Included files

- `new-wave-it-brand-guide.pdf` - 12-page production brand guide covering strategy, logo usage, palette, typography, graphic language, accessibility, digital usage, social safe areas, and operational applications.
- `new-wave-it-brand-preview-2400x1800.png` - high-resolution overview sheet for quick visual review.

## Approved brand anchors

- Primary promise: **Technology that keeps business moving.**
- Heritage line: **Don't get lost in the current**
- Primary palette:
  - Deep Current: `#09131D`
  - Current Navy: `#101E2D`
  - Signal Cyan: `#31C6CF`
  - Continuity Green: `#62BE68`
  - Tide Blue: `#317B92`
  - Cloud White: `#F7FAFB`
  - Mist Gray: `#E8EFF1`
  - Slate: `#526271`

## Governance
